How to run / 三种用法

同一套工具，三种用法。
照团队大小挑。

01 / 自己用

打开浏览器，六件都能用

工具装在自己的电脑上，打开就开工。寻客分档、清收出函、设施看状态、车场算收入、抓表对账、清洗归集——按你的顺序来。

  • 多张 Excel / CSV 一次拖入，自动归集分级出函
  • 六件工具各管一件事，步骤固定不返工
  • 结果留在自己手上，换个人接手也看得懂
适合 单人使用、看重数据自己掌握
02 / 团队

三张表，三件工作台定时同步

清收读欠费台账、设施读设备表、停车读收入表，各读各的。三张表放团队空间，电脑上的 WorkBuddy 每天定时抓取、自动重算，刷新清单与报表。

  • 三件事三张表，各自口径清楚，不混在一起
  • 每天早上自动同步一次，清单和报表跟着刷新
  • 需一台电脑上的 WorkBuddy 保持运行
适合 小团队协作、一天更新一次
03 / 在线 · 推荐

发布成应用，链接发下去

每人 10 个免费名额，清收、设施、停车一键发布成在线应用，云端全自动抓取表格、持续运行；链接发下去，打开就能用。

  • 全自动抓取，数据实时同步，不依赖任何一台电脑开机
  • 多地团队各看各的表，随时可查
  • 名额循环使用，替换和删除都不收钱
适合 多地团队、要求随时可用
